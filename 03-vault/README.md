# 03 — الخزنة (Vault)

خزنة عامة لأي شيء مهم يجب ألا يضيع: مراجع، ملاحظات، وثائق، معلومات متفرقة.

## المجلدات
- `credentials-notes/` — ملاحظات عن الوصول والحسابات (**بلا أسرار خام** — لا توكنات/كلمات مرور. فقط: أي حساب، أين، ملاحظات). الأسرار الحقيقية تبقى خارج المستودع.
- `references/` — مراجع ووثائق مهمة (قواعد، معايير، روابط).
- `misc/` — أي شيء آخر يستحق الحفظ.

## قاعدة ذهبية
⛔ **ممنوع رفع أسرار خام** (GitHub tokens, API keys, passwords). `.gitignore` في الجذر يحمي، لكن المسؤولية أولاً على ما نكتبه.
