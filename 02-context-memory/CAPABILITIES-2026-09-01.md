# قدرات البنّاء الرئيسي — فحص فعلي 2026-09-01 (كل بند مثبت بأمر منفذ)

## 1) الوكلاء الفرعيون المتوازيون ✅ متاح بطريقتين

### أ) `gsk task create` — وكلاء Genspark كاملون (مثبت: gsk task --help)
- أنواع: `super_agent` (وكيل عام)، `deep_research` (بحث عميق)، `cross_check` (تدقيق متقاطع)، docs/slides/website...
- أوامر إدارة: `status` (متابعة)، `events` (بث حي)، `continue` (متابعة حوار)، `stop`
- **⚠️ قيدان مهمان:**
  1. كل task يُحاسب من رصيد المالك — لا يُطلق وكيل إلا بحاجة حقيقية وبموافقة
  2. الوكيل الفرعي **لا يرث سياق الأب** — يجب تضمين كل السياق/الروابط في نص المهمة (وهنا قوة allpro: نعطيه روابط الوثائق)

### ب) عمليات خلفية متوازية محلياً (Bash background) — مجانية
- تشغيل builds/فحوصات/تحليلات بيانات متوازية في نفس البيئة ومراقبتها — مناسبة لأغلب احتياجاتنا

### قاعدة الاستخدام المعتمدة
- تحليل بيانات/كود/قياسات → محلياً وبالتوازي الخلفي (صفر تكلفة)
- بحث خارجي ضخم أو تدقيق متقاطع مستقل → `gsk task` **بعد موافقة المالك** (لأنه مدفوع)

## 2) مهارات Genspark ✅ متاح سحبها — 60 مهارة مثبتة
- الأمر: `gsk init-skills` — سحبت الكتالوج فعلياً: **60 مهارة**
- الأهم لمشروعنا:

| المهارة | فائدتها لكيف الضيافة |
|---|---|
| gsk-web-search / gsk-crawler / gsk-batch-crawl | بحوث المنافسين وSERP |
| gsk-create-task + task-status/continue | إطلاق وكلاء فرعيين |
| gsk-cross-check (نوع task) | تدقيق متقاطع للتقارير الواردة — يخدم قاعدة «تحقق قبل البناء» |
| gsk-maps-search | فحص المنافسين في Local Pack (خرائط جوجل) |
| gsk-understand-images / analyze-media | تحليل لقطات SERP والمنافسين |
| gsk-github | عمليات GitHub |
| gsk-google-sheets/docs | لو أرسل الوكلاء بيانات بصيغ Google |
| gsk-social-instagram | تحليل حضور المنافسين في إنستغرام (40% من SERP اجتماعي) |
| gsk-scholar-search | مصادر رسمية عند الحاجة |

- ملاحظة: لا توجد مهارة باسم «CEO» في كتالوج الـ60 — الموجود مهارات أدوات. المهارات المتاحة للتفعيل المباشر في بيئتي: نشر/استضافة + هذه الـ60 عبر gsk

## الخلاصة التشغيلية
- التوازي: نعم (محلي مجاني + وكلاء gsk مدفوعون بموافقة)
- المهارات: نعم، 60 مهارة قابلة للسحب والاستخدام عند الحاجة
- كل استخدام مدفوع يُستأذن فيه المالك أولاً
