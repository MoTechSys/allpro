# 01 — مشروع «كيف الضيافة»

هدف المشروع: جعل **keifaldiafa.com** النتيجة #1 في جوجل لاستعلامات الضيافة في جدة (قهوجيين، صبابين، ضيافة أعراس...) + المصدر الذي تقتبسه محركات الذكاء الاصطناعي. الجوال أولاً (95% من الزوار).

## المحتوى

| # | التقرير |

- `lh-*.json` — تقارير Lighthouse كاملة (الرئيسية + portfolio + offerings + services)

- `comp-*.json` — تحليل المنافسين (kahwgysa وغيره)
