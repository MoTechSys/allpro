### نقاط قوّته (نتعلّم منها)
| # | القوة | الدرس لنا |
|---|---|---|
| K1 | **سلطة الصفحة الواحدة** — كل الكلمات + الصور + النموذج + التواصل في صفحة واحدة مركّزة | العمق يهزم العدد (مؤكّد) |

| K3 | **نموذج حجز مربوط بواتساب** (نوع المناسبة/العدد/الحي/التاريخ) | تحويل مباشر منخفض الاحتكاك |

### ثغراته (نستغلّها للتفوّق)
| # | الثغرة | كيف نتفوّق |
|---|---|---|
| KW1 | 🔴 **عدّادات صفرية تالفة** («0+ سنة خبرة», «0+ مناسبة») → يوحي بموقع مهجور | أرقامنا الموثّقة (من صاحب المشروع فقط) تعمل بلا أعطال |
| KW2 | 🔴 **أخطاء إملائية** («ايسوعية») + صياغة ركيكة | محتوى محرَّر باحتراف |
| KW3 | 🔴 **تصميم قديم مزدحم** (بني/ذهبي عتيق) | فخامتنا الحديثة (ذهبي مطفأ + أسود + مساحات) |
| KW4 | 🔴 **keyword stuffing** فجّ في التذييل (سبام مرئي) | نص طبيعي + تغطية دلالية أنيقة |
| KW5 | صفحة واحدة فقط = **سقف نمو محدود** بالنيّات | نتوسّع بالنيّات المستقلة (أسعار، نسائية، شركات...) |

## 3. المنافسة حسب فئة الاستعلام

### أ) استعلامات القهوجيين/الصبابين (الأعلى حجماً) — **نحن غائبون**
- المتصدّرون: kahwgysa + haraj + instagram + qahwajiin.com + al-mostakbl
- **نمط الفائز:** صفحة هبوط مركّزة + أرقام تواصل بارزة + صور طاقم حقيقية + حداثة (حراج: "قبل ٣ أيام")
- **خطة التفوّق:** صفحة نيّة مستقلة «قهوجيين وصبابين قهوة في جدة» — سلطة صفحة واحدة عميقة، صور طاقمنا الحقيقية، نموذج واتساب، تغطية المترادفات نصياً. + حضور إنستغرام متزامن.

### ب) ضيافة الأعراس — **نتصدّرها asoul (1)، نحن (2)**
- منافسة داخلية شقيقة + tiktok/instagram + zafaf.sa (قاعات)
- **خطة:** تعميق صفحة ضيافة الأعراس بعناصر جدة الحقيقية (قاعات بالاسم، لوجستيات، شهادات موثّقة) لتجاوز المركز 2.

### ج) ركن القهوة العربية — **asoul (3)، نحن غائبون**
- المتصدّر: coffeeworld2021 (بيع أجهزة) + haraj — **نيّة مختلطة** (منتج vs خدمة)
- **خطة:** صفحة «ركن قهوة عربية للمناسبات» بنيّة الخدمة الواضحة (لا بيع أجهزة) — تمايز عن نيّة المنتج.

### د) تنسيق/تجهيز الحفلات — **نحن غائبون**
- instagram + starsparties + tiktok + zafaf + haraj — **مشتّت بلا مسيطر**
- **خطة:** صفحة «تجهيز ضيافة حفلات» بزاوية الضيافة تحديداً (لا تنسيق ديكور) — نيّة فرعية واضحة.
