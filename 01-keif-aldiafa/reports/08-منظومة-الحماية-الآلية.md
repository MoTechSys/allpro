# 08) منظومة الحماية الآلية (QA Guardian)

## ملخص تنفيذي

هذا التقرير يبني **بوابة جودة CI صارمة** لمستودع `keif-aldiafa-web` (Next.js 14)، مع تحويل فحوصات المرجع من:

- `../osoul-aldiafa-v2/scripts/seo-guard.mjs`
- `../osoul-aldiafa-v2/scripts/similarity-check.mjs`
- `../osoul-aldiafa-v2/scripts/a11y-audit.mjs`
- `../osoul-aldiafa-v2/scripts/perf-audit.mjs`

إلى منظومة مكيّفة على المشروع الحالي، وفق شروطك:

1. `seo-guard` (العنوان 50-60، الوصف 120-158، H1 واحد، منع `address` و`LocalBusiness`)
2. `similarity-check` (تشابه صفحات المدن ≤ 55%)
3. Lighthouse CI (`SEO=100`، أداء `>=90`، وصولية `>=95`)
4. اختبار المحتوى بدون JavaScript (شرط فهرسة)
5. تدقيق WCAG 2.2

وأي فشل في أي بوابة ⇒ **يفشل البناء بالكامل**.

---

## أولاً: ماذا يفحص سكربتا المرجع فعلياً

### A) `seo-guard.mjs` (مرجع `osoul-aldiafa-v2`)

السكربت المرجعي يعمل على HTML الناتج من `next build` داخل `.next/server/app`، ويركز على:

- طول `title` وحدوده
- تكرار اسم العلامة داخل نفس العنوان
- تكرار العنوان بين صفحتين
- وجود/طول/تكرار `meta description`
- عدد `H1` وصحته
- تسلسل العناوين (`h2 -> h4` قفزات)
- `canonical`
- سلامة JSON-LD + منع `LocalBusiness` + منع `address`
- كلمات محظورة دلالياً
- ادعاءات رقمية غير موثقة
- حد أدنى للروابط الداخلية
- فحص تشابه عبر استدعاء `similarity-check`
- فحوصات OG متقدمة
- فحص `sameAs` الشبكي (اختياري)
- اتساق المناطق بين UI وSchema

> ملاحظة: في المرجع، بعض البنود تحذير (`warn`) وبعضها كسر (`error`) عبر آلية baseline-gate.

### B) `similarity-check.mjs` (مرجع `osoul-aldiafa-v2`)

يفحص التشابه النصي بعد:

- إزالة `header/nav/footer`
- نزع السكربتات والستايل
- تحييد أسماء المدن إلى placeholder
- تطبيع النص
- حساب تشابه بنسبة token-overlap (`ratio`)

ثم يعلن مخالفة إذا تجاوزت الأزواج العتبة (`SIM_MAX`, افتراضياً `0.55`).

## ثانياً: التكييف على مستودع `keif-aldiafa-web`

### نطاق الصفحات المستهدفة

- فحص SEO على جميع الصفحات indexable في `.next/server/app/**/*.html`
- فحص التشابه على صفحات المدن الخدمية من نمط:
  - `/sababin-qahwa-<city>`
  - `/qahwajiin-<city>`
  - `/diyafa-munasabat-<city>`

### العتبات المعتمدة

- `title`: من `50` إلى `60` حرفاً (شامل)
- `description`: من `120` إلى `158` حرفاً (شامل)
- `H1`: واحد فقط وغير فارغ
- JSON-LD: ممنوع وجود `@type=LocalBusiness`
- JSON-LD: ممنوع أي حقل باسم `address`
- تشابه صفحات المدن: `<= 55%`
- Lighthouse:
  - `performance >= 0.90`
  - `accessibility >= 0.95`
  - `seo = 1.00`
- WCAG 2.2: صفر مخالفات في `axe` (tags WCAG2.2)
- No-JS: المحتوى الرئيسي يجب أن يظهر نصياً في DOM بدون JS

## رابعاً: كود `seo-guard.mjs` مكيّف للمستودع الحالي

ضع الملف التالي في:

`/scripts/seo-guard.mjs`

```js
#!/usr/bin/env node
import { existsSync, readFileSync, readdirSync } from "node:fs";
import { join, relative } from "node:path";
import { computeCitySimilarity, SIM_MAX } from "./similarity-check.mjs";

const ROOT = process.cwd();
const APP_DIR = join(ROOT, ".next", "server", "app");

if (!existsSync(APP_DIR)) {
  console.error("❌ لم يُعثر على .next/server/app — شغّل npm run build أولاً");
  process.exit(1);
}

const TITLE_MIN = 50;
const TITLE_MAX = 60;
const DESC_MIN = 120;
const DESC_MAX = 158;

function walk(dir, out = []) {
  for (const entry of readdirSync(dir, { withFileTypes: true })) {
    const full = join(dir, entry.name);
    if (entry.isDirectory()) walk(full, out);
    else if (entry.name.endsWith(".html")) out.push(full);
  }
  return out;
}

function pick(html, regexes) {
  for (const re of regexes) {
    const match = html.match(re);
    if (match?.[1]) return match[1].trim();
  }
  return null;
}

function textOnly(value) {
  return value ? value.replace(/<[^>]+>/g, " ").replace(/\s+/g, " ").trim() : "";
}

function len(value) {
  return Array.from(value).length;
}

function isSystemPage(slug) {
  return /^(_not-found|404|500|robots|sitemap|opengraph-image)/.test(slug);
}

function hasNoIndex(html) {
  const robots = pick(html, [
    /<meta[^>]+name=["']robots["'][^>]+content=["']([^"']*)["']/i,
    /<meta[^>]+content=["']([^"']*)["'][^>]+name=["']robots["']/i,
  ]);
  return robots ? /\bnoindex\b/i.test(robots) : false;
}

function unescapeJsonLd(raw) {
  return raw
    .replace(/\\u003c/g, "<")
    .replace(/\\u003e/g, ">")
    .replace(/\\u0026/g, "&");
}

function walkJson(node, onObject) {
  if (Array.isArray(node)) {
    for (const item of node) walkJson(item, onObject);
    return;
  }
  if (!node || typeof node !== "object") return;
  onObject(node);
  for (const value of Object.values(node)) walkJson(value, onObject);
}

const files = walk(APP_DIR);
const errors = [];
let checkedPages = 0;

for (const file of files) {
  const html = readFileSync(file, "utf8");
  if (!/<html[\s>]/i.test(html)) continue;

  const rel = relative(APP_DIR, file).replace(/\\/g, "/");
  const slug = rel.replace(/\.html$/, "");

  if (isSystemPage(slug)) continue;
  if (hasNoIndex(html)) continue;

  checkedPages += 1;

  const title = pick(html, [/<title[^>]*>([\s\S]*?)<\/title>/i]);
  if (!title) {
    errors.push(`SEO-TITLE · ${slug}: title مفقود`);
  } else {
    const l = len(textOnly(title));
    if (l < TITLE_MIN || l > TITLE_MAX) {
      errors.push(`SEO-TITLE · ${slug}: طول العنوان ${l} (المطلوب ${TITLE_MIN}-${TITLE_MAX})`);
    }
  }

  const description = pick(html, [
    /<meta[^>]+name=["']description["'][^>]+content=["']([^"']*)["']/i,
    /<meta[^>]+content=["']([^"']*)["'][^>]+name=["']description["']/i,
  ]);

  if (!description) {
    errors.push(`SEO-DESC · ${slug}: description مفقود`);
  } else {
    const l = len(description);
    if (l < DESC_MIN || l > DESC_MAX) {
      errors.push(`SEO-DESC · ${slug}: طول الوصف ${l} (المطلوب ${DESC_MIN}-${DESC_MAX})`);
    }
  }

  const h1Matches = [...html.matchAll(/<h1\b[^>]*>([\s\S]*?)<\/h1>/gi)];
  if (h1Matches.length !== 1) {
    errors.push(`SEO-H1 · ${slug}: عدد H1 = ${h1Matches.length} (المطلوب 1)`);
  } else {
    const h1Text = textOnly(h1Matches[0][1]);
    if (!h1Text) errors.push(`SEO-H1 · ${slug}: H1 فارغ`);
  }

  const jsonLdBlocks = [...html.matchAll(/<script[^>]+type=["']application\/ld\+json["'][^>]*>([\s\S]*?)<\/script>/gi)];

  for (const block of jsonLdBlocks) {
    try {
      const parsed = JSON.parse(unescapeJsonLd(block[1]));
      walkJson(parsed, (obj) => {
        const t = obj["@type"];
        if (typeof t === "string" && t === "LocalBusiness") {
          errors.push(`SEO-SCHEMA · ${slug}: ممنوع استخدام LocalBusiness`);
        }
        if (Array.isArray(t) && t.includes("LocalBusiness")) {
          errors.push(`SEO-SCHEMA · ${slug}: ممنوع استخدام LocalBusiness`);
        }
        if (Object.prototype.hasOwnProperty.call(obj, "address")) {
          errors.push(`SEO-SCHEMA · ${slug}: ممنوع وجود الحقل address`);
        }
      });
    } catch {
      errors.push(`SEO-SCHEMA · ${slug}: JSON-LD غير صالح (لا يمر JSON.parse)`);
    }
  }
}

const sim = computeCitySimilarity();
for (const pair of sim.violations) {
  errors.push(
    `SIMILARITY · ${pair.service}: ${(pair.ratio * 100).toFixed(2)}% بين ${pair.a} و ${pair.b} (الحد ${(SIM_MAX * 100).toFixed(0)}%)`
  );
}

console.log("── SEO Guard (Keif) ──");
console.log(`Pages checked: ${checkedPages}`);
console.log(`City pairs checked: ${sim.totalPairs}`);

if (errors.length) {
  console.error(`\n❌ Found ${errors.length} violations:\n`);
  for (const error of errors) console.error(`- ${error}`);
  process.exit(1);
}

console.log("✅ All SEO guard checks passed.");
```

## خامساً: سكربت التشابه المكيّف (`similarity-check.mjs`)

ضع الملف التالي في:

`/scripts/similarity-check.mjs`

```js
#!/usr/bin/env node
import { existsSync, readFileSync, readdirSync } from "node:fs";
import { basename, join } from "node:path";

const ROOT = process.cwd();
const APP_DIR = join(ROOT, ".next", "server", "app");

export const SIM_MAX = Number(process.env.SIM_MAX ?? 0.55);

const CITY_SLUGS = ["jeddah", "riyadh", "makkah", "madinah", "dammam", "taif", "abha", "yanbu"];
const CITY_TOKENS = [
  "جدة", "الرياض", "مكة", "المكرمة", "المدينة", "المنورة", "الدمام", "الطائف", "أبها", "ينبع",
  "jeddah", "riyadh", "makkah", "madinah", "dammam", "taif", "abha", "yanbu",
];

function walk(dir, out = []) {
  if (!existsSync(dir)) return out;
  for (const entry of readdirSync(dir, { withFileTypes: true })) {
    const full = join(dir, entry.name);
    if (entry.isDirectory()) walk(full, out);
    else if (entry.name.endsWith(".html")) out.push(full);
  }
  return out;
}

function extractVisibleText(html) {
  let text = html;
  text = text.replace(/<script[\s\S]*?<\/script>/gi, " ");
  text = text.replace(/<style[\s\S]*?<\/style>/gi, " ");
  text = text.replace(/<header\b[\s\S]*?<\/header>/gi, " ");
  text = text.replace(/<nav\b[\s\S]*?<\/nav>/gi, " ");
  text = text.replace(/<footer\b[\s\S]*?<\/footer>/gi, " ");
  text = text.replace(/<[^>]+>/g, " ");
  text = text.replace(/&[a-zA-Z#0-9]+;/g, " ");
  text = text.replace(/[\u060C\u061B\u061F.,;:!?()«»"'\-\u2013\u2014]/g, " ");
  return text.replace(/\s+/g, " ").trim();
}

function neutralize(text) {
  let normalized = text.toLowerCase();
  for (const token of CITY_TOKENS) {
    normalized = normalized.split(token.toLowerCase()).join("__city__");
  }
  return normalized;
}

function ratio(aTokens, bTokens) {
  if (aTokens.length === 0 && bTokens.length === 0) return 1;
  if (aTokens.length === 0 || bTokens.length === 0) return 0;
  const countB = new Map();
  for (const token of bTokens) countB.set(token, (countB.get(token) || 0) + 1);
  let matches = 0;
  for (const token of aTokens) {
    const count = countB.get(token) || 0;
    if (count > 0) {
      matches += 1;
      countB.set(token, count - 1);
    }
  }
  return (2 * matches) / (aTokens.length + bTokens.length);
}

function parseServiceCity(stem) {
  for (const city of CITY_SLUGS) {
    const suffix = `-${city}`;
    if (stem.endsWith(suffix)) {
      return { service: stem.slice(0, -suffix.length), city };
    }
  }
  return null;
}

function loadCityPages() {
  const htmlFiles = walk(APP_DIR);
  const pages = [];

  for (const file of htmlFiles) {
    const stem = basename(file, ".html");
    const parsed = parseServiceCity(stem);
    if (!parsed) continue;
    if (!["sababin-qahwa", "qahwajiin", "diyafa-munasabat"].includes(parsed.service)) continue;

    const html = readFileSync(file, "utf8");
    const text = neutralize(extractVisibleText(html));
    const tokens = text.split(" ").filter(Boolean);
    if (tokens.length < 40) continue;

    pages.push({
      slug: stem,
      service: parsed.service,
      city: parsed.city,
      tokens,
    });
  }

  return pages;
}

export function computeCitySimilarity() {
  if (!existsSync(APP_DIR)) {
    throw new Error("لم يُعثر على .next/server/app — شغّل npm run build أولاً");
  }

  const pages = loadCityPages();
  const pairs = [];

  for (let i = 0; i < pages.length; i += 1) {
    for (let j = i + 1; j < pages.length; j += 1) {
      if (pages[i].service !== pages[j].service) continue;
      const currentRatio = ratio(pages[i].tokens, pages[j].tokens);
      pairs.push({
        service: pages[i].service,
        a: pages[i].slug,
        b: pages[j].slug,
        ratio: currentRatio,
      });
    }
  }

  pairs.sort((x, y) => y.ratio - x.ratio);
  const violations = pairs.filter((pair) => pair.ratio > SIM_MAX);

  return {
    pagesCount: pages.length,
    totalPairs: pairs.length,
    pairs,
    violations,
  };
}

if (import.meta.url === `file://${process.argv[1]}`) {
  const result = computeCitySimilarity();

  console.log("── Similarity Check (City pages) ──");
  console.log(`Pages: ${result.pagesCount}`);
  console.log(`Pairs: ${result.totalPairs}`);
  console.log(`Threshold: ${(SIM_MAX * 100).toFixed(0)}%`);

  if (result.pairs.length) {
    console.log("\nTop pairs:");
    for (const pair of result.pairs.slice(0, 12)) {
      console.log(`- ${(pair.ratio * 100).toFixed(2)}% | ${pair.a} <-> ${pair.b}`);
    }
  }

  if (result.violations.length) {
    console.error(`\n❌ ${result.violations.length} pair(s) تجاوزت العتبة:`);
    for (const pair of result.violations) {
      console.error(`- ${(pair.ratio * 100).toFixed(2)}% | ${pair.a} <-> ${pair.b}`);
    }
    process.exit(1);
  }

  console.log("\n✅ City similarity gate passed.");
}
```

## سادساً: فحص ظهور المحتوى بدون JS

ضع الملف التالي في:

`/scripts/no-js-content-check.mjs`

```js
#!/usr/bin/env node
import { chromium } from "playwright";

const BASE = process.env.BASE_URL || "http://127.0.0.1:3000";
const URLS = [
  "/",
  "/services",
  "/offerings",
  "/about",
  "/contact",
  "/locations",
  "/qahwajiin-jeddah",
  "/sababin-qahwa-riyadh",
  "/diyafa-munasabat-makkah",
];

const browser = await chromium.launch();
const context = await browser.newContext({ javaScriptEnabled: false });

const violations = [];

for (const path of URLS) {
  const page = await context.newPage();
  const url = `${BASE}${path}`;
  await page.goto(url, { waitUntil: "domcontentloaded", timeout: 60000 });

  const result = await page.evaluate(() => {
    const h1Count = document.querySelectorAll("h1").length;
    const mainText = (document.querySelector("main")?.textContent || "")
      .replace(/\s+/g, " ")
      .trim();
    const bodyText = (document.body?.textContent || "")
      .replace(/\s+/g, " ")
      .trim();
    return {
      h1Count,
      mainTextLen: mainText.length,
      bodyTextLen: bodyText.length,
    };
  });

  if (result.h1Count !== 1) {
    violations.push(`${path}: عدد H1 بدون JS = ${result.h1Count}`);
  }
  if (result.mainTextLen < 120) {
    violations.push(`${path}: المحتوى الرئيسي بدون JS قصير (${result.mainTextLen})`);
  }
  if (result.bodyTextLen < 300) {
    violations.push(`${path}: DOM النصي بدون JS ضعيف (${result.bodyTextLen})`);
  }

  await page.close();
}

await context.close();
await browser.close();

if (violations.length) {
  console.error("❌ No-JS indexing gate failed:");
  for (const item of violations) console.error(`- ${item}`);
  process.exit(1);
}

console.log("✅ No-JS content visibility gate passed.");
```

`/scripts/wcag22-audit.mjs`

```js
#!/usr/bin/env node
import { chromium } from "playwright";
import AxeBuilder from "@axe-core/playwright";

const BASE = process.env.BASE_URL || "http://127.0.0.1:3000";
const URLS = [
  "/",
  "/services",
  "/offerings",
  "/about",
  "/contact",
  "/locations",
  "/portfolio",
  "/social",
  "/qahwajiin-jeddah",
];

const TAGS = ["wcag2a", "wcag2aa", "wcag21a", "wcag21aa", "wcag22a", "wcag22aa"];

const browser = await chromium.launch();
const context = await browser.newContext({ viewport: { width: 1440, height: 900 } });

const violations = [];

for (const path of URLS) {
  const page = await context.newPage();
  const url = `${BASE}${path}`;

  await page.goto(url, { waitUntil: "load", timeout: 60000 });
  await page.waitForTimeout(1200);

  const result = await new AxeBuilder({ page }).withTags(TAGS).analyze();

  if (result.violations.length > 0) {
    for (const violation of result.violations) {
      violations.push(
        `${path} | ${violation.id} | impact=${violation.impact ?? "n/a"} | nodes=${violation.nodes.length}`
      );
    }
  }

  await page.close();
}

await context.close();
await browser.close();

if (violations.length) {
  console.error("❌ WCAG 2.2 gate failed:");
  for (const v of violations) console.error(`- ${v}`);
  process.exit(1);
}

console.log("✅ WCAG 2.2 gate passed (no axe violations).");
```
