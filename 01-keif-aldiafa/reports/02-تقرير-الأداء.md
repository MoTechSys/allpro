## 2. الأسباب الجذرية (بأدلة القياس)

### 🔴 P0-1: Google Tag Manager يحجب الخيط الرئيسي → TBT
**الدليل (network + unused-js):**
- `gtag/js?id=G-ZZHYDVVMT1` = **186KB** (منها 78KB غير مستخدم)
- `gtag/js?id=AW-11081441847` = **158KB** (منها 58KB غير مستخدم)
- **مجموع 344KB جافاسكربت طرف ثالث** يُحمّل ويُنفّذ → السبب الأول لـ TBT 1000ms.
- الجذر: `src/app/layout.tsx:201` — سكربت GA inline (رصده lint أيضاً: `next-script-for-ga`).

**الحل الجذري:**
1. نقل GTM/GA إلى `next/script` بـ `strategy="afterInteractive"` أو `lazyOnload` (لا يحجب التحميل الأولي).
2. تحميل وسم الإعلانات (`AW-`) فقط عند نيّة التحويل (تفاعل/تمرير) — لا في التحميل الأولي.
3. النتيجة المتوقعة: TBT ينزل من 1000ms إلى < 250ms.

### 🔴 P0-2: هيرو فيديو يؤخّر LCP
**الدليل:** `/videos/hero-bg.mp4` = **280KB** أكبر أصل على الرئيسية، يُحمّل في المقدّمة.
**الحل الجذري:**
1. **poster ثابت مُحسّن** (WebP/AVIF < 80KB) يظهر فوراً كـ LCP، والفيديو يُحمّل `preload="none"` ويشتغل بعد التفاعل/الظهور.
2. أو استبدال الفيديو بصورة هيرو حقيقية عالية الجودة (من أرشيف مناسبات فعلية — يخدم الفخامة + السيو).
3. `fetchpriority="high"` لعنصر LCP الفعلي (الصورة/poster).
4. النتيجة المتوقعة: LCP ينزل من 9.2s إلى < 2.5s.

### 🟠 P1-1: الخطوط (woff2) بلا preload
**الدليل:** خطّان woff2 (35KB + 32KB) يُحمّلان دون `preload` → FOIT/تأخير نص.
**الحل:** `preload` للخط الأساسي فقط + `font-display: swap` + subsetting عربي (إسقاط اللاتيني غير المستخدم).

### 🟠 P1-2: الصور — الحجم والصيغة
**الدليل:** `/portfolio` (107 صورة) + `/offerings` (122) + `/services` (97) → LCP 7.7–8.4s.
**الحل الجذري (خط إنتاج — يُنسّق مع الوكيل 6):**
1. كل الصور WebP/AVIF متعدد المقاسات (srcset) عبر `next/image`.
2. أي صورة > 250KB تُضغط ذكياً (الميزانية الملزمة).
3. `loading="lazy"` لكل ما تحت الطيّة + `sizes` صحيح للـ lightbox.
4. أول صورة مرئية فقط `priority`.
