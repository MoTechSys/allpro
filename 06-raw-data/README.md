1. **كل ملف خام يُحفظ هنا كما وصل** (ZIP كامل بدون فك أو تعديل).
2. **ممنوع التعديل على أي ملف داخل هذا المجلد** — للقراءة فقط.
3. كل دفعة خام لها مجلد باسم `YYYY-MM-DD-<المصدر>-<الموضوع>/` وبداخله:
   - الملف الخام نفسه
   - `RAW-MANIFEST.md` — بصمة sha256 + المصدر + الجرد الكامل
4. **المعالجة والتحليل لا تُكتب هنا أبداً** — مكانها:
   - `01-keif-aldiafa/data/` (بيانات معالجة/مشتقة)
   - `05-incoming-research/analyzed/` (تقارير التحليل)
