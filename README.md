## القواعد
- **لا أسرار خام في المستودع** (توكنات/مفاتيح تُحفظ خارجه)
- كل رسالة مالك جديدة → ملف مؤرخ في `04-owner-messages/` فوراً
- كل بحث وارد → `05-incoming-research/inbox/` ثم حكم متحقق في `analyzed/`

- `STATE.md` يُحدَّث قبل نهاية كل جلسة — هو نقطة التسليم بين الوكلاء
- التحديثات بـ Conventional Commits (feat/fix/docs/chore...)
