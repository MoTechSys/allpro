# allpro — المستودع الرئيسي للعمل

مستودع منظّم يحفظ كل الأعمال والأبحاث والسياق بحيث لا يضيع أي شيء.

## الهيكلية

```
allpro/
├── 01-keif-aldiafa/        ← مشروع «كيف الضيافة» (البحوث والتقارير)
│   ├── reports/            ← 10 تقارير كاملة (00–09) بالعربية
│   ├── data/              ← بيانات خام (Lighthouse JSON, SERP, تحليل منافسين)
│   ├── screenshots/       ← فهرس اللقطات (جوال/ديسكتوب)
│   ├── archive/           ← الأرشيف المضغوط (نفس محتوى رابط التحميل)
│   └── CONTEXT.md         ← ملخص المهمة والمصادر
│
├── 02-context-memory/      ← ذاكرة السياق (ما نشتغل عليه + الحالة + القرارات)
│   ├── 2026-08-31.md      ← لقطة كاملة لحالة المشروع والبيئة
│   └── ENGINEERING.md     ← بيئة العمل والمحركات والمعايير
│
└── 03-vault/               ← خزنة عامة لأي شيء مهم لا يضيع
    ├── credentials-notes/ ← ملاحظات وصول (بلا أسرار خام)
    ├── references/        ← مراجع ووثائق
    └── misc/              ← متفرقات
```

## القواعد
- **لا أسرار خام في المستودع** (توكنات/مفاتيح تُحفظ خارجه). `.gitignore` يحمي من التسريب.
- كل مجلد له README يشرح محتواه.
- التحديثات بـ Conventional Commits (feat/fix/docs/chore...).
