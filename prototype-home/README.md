## التسلسل
أرِني (هيرو + فهرس) → أقنعني (لمن نخدم → من وثق بنا → أعمالنا) → فهّمني (الطاقم → التقديمات → الخدمات → المدن → أسئلة) → كلّمني (واتساب).

## قرارات ثابتة
- لا أسعار؛ الأرقام الوحيدة: «+500 مناسبة»، «منذ 2016».
- لا اسم/شعار جهة حكومية جديدة بدون موافقة كتابية — صور الميدان فقط (اللافتات في الصور ظاهرة أصلاً في /portfolio المنشور).
- شعارات الشركات = نفس الـ23 جهة الظاهرة حالياً في الموقع.
- واتساب واحد: 966508252134 (عرض 0508252134).
