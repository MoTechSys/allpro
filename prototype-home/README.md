# prototype-home — نموذج الصفحة الرئيسية (للمراجعة فقط)

**الحالة:** v1 · 2026-09-03 · بانتظار رأي المالك («تمام» أو تعديلات).

**ما هذا؟** تنفيذ بصري لمقترح W-UX v2 (التقرير 19 §8.4) في مجلد فرعي مستقل:
- لا يلمس الإنتاج (keif-v2) ولا مستودع العمل (keif-aldiafa-web).
- ملف HTML واحد + CSS مضمّن + 32 صورة منسوخة/مصغّرة + 23 شعارًا (نفس الجهات الظاهرة في الموقع بلا تكرار).
- `noindex` — لا يُفهرس.

## الترتيب (أرِني → أقنعني → كلّمني)

| 2 | «لمن نخدم؟» 4 كروت | شركات · مؤسسات · جهات حكومية · مناسبات خاصة وعامة — طبقة B2B فوق بنية SEO |

## قرارات مقصودة
- واتساب مدخل واحد (أيقونة في الهيدر + زر عائم يختفي عند قسم التواصل + زر CTA).
- بلا جسيمات/حركات ثقيلة، بلا فيديو، بلا يوتيوب، بلا أسعار، بلا أرقام غير موثقة.
- الشعارات: 23 جهة فريدة من الـ30 الظاهرة حاليًا (حُذفت النسخ المكررة _Alt)؛ استُبدلت 5 بنسخ أعلى دقة لنفس الجهة من `partner-N.webp`. الشعارات غير الظاهرة حاليًا (وزارات، ريتز…) **لم تُعرض** بانتظار موافقة كتابية.

## تشغيل محلي
```
cd prototype-home && python3 -m http.server 8787
```
