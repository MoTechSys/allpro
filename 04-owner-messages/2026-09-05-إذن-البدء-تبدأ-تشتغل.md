# إذن البدء — «تبدأ تشتغل»

**التاريخ:** 2026-09-05
**نص المالك (حرفيًا):**

> ياغالي ابدا اشتغل المهم تبدا هيا

**التفسير:** هذا هو إذن البدء المنصوص عليه في القاعدة («كلمتك: تبدأ تشتغل»). تُنفَّذ الآن كل الملاحظات المسجَّلة (1–6 + Q1–Q6) على صفحة النموذج `qahwajiin-jeddah.html` بالترتيب المتفق:
1. الدراسة المقارنة لأفضل مواقع المجال → هيكلية مقترحة مرتَّبة بالأهمية.
2. إصلاح الصور الطويلة (.svc) بالجوال → صور صغيرة + لايت بوكس.
3. إصلاح فراغ «شركاء النجاح» بالجوال.
4. زر انتقال للصفحة العامة تحت كل قسم عيّنة.
5. صف الأيقونات (واتساب + كل الحسابات) في آخر الصفحة.
6. إعادة ترتيب الأقسام حسب الأهمية، بلا تعقيد أو تداخل.
7. فحص 390/1440 + لقطات كل قسم + Lighthouse → رفع → مزامنة khadamat.
